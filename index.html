Gravity Simulator

About This Gravity Simulator

This mobile friendly 2D interactive gravity simulator is a real-time physics sandbox that lets you explore orbital mechanics, gravitational interactions, and motion in space. You can create celestial bodies, adjust their position and velocity, and observe how they influence each other through gravity.

Built using HTML5 Canvas and JavaScript, this simulation models realistic gravitational behavior, allowing users to experiment with orbits, collisions, and multi-body systems. Whether you're learning physics, testing orbital setups, or just experimenting, this tool provides a hands-on way to visualize complex motion.

Key features include dynamic zooming, body focusing, velocity visualization, and full control over object properties. The simulator is designed to work on both desktop and mobile devices, making it accessible for learning and experimentation anywhere.

This gravity sandbox is ideal for students, educators, and anyone interested in space physics, orbital mechanics, or interactive simulations.

How to Use the Gravity Simulator

Creating Bodies

Use the "Create Body" tools to add new objects to the simulation. Select a body type, then click on the canvas to place it. Each body will interact gravitationally with others in real time.

Adjusting Position and Velocity

Click on a body to select it. You can drag it to change its position or adjust its velocity by dragging the velocity arrow. Fine-tune values using the input fields for precise control.

Camera Controls

Use your mouse or touch gestures to pan and zoom around the simulation. You can also select a body from the focus menu to lock the camera onto it.

Editing and Deleting

Use the modify tools to update body properties or remove objects from the simulation. You can also clear trails to reset visual paths.

Mobile Controls

On smaller screens, use the toggle arrow to open the tools panel. The interface is optimized for touch, including drag interactions and pinch-style navigation.

Tips for Exploration

  • Try giving a body sideways velocity to create an orbit
  • Use different masses to see how gravity changes motion
  • Create multiple bodies to simulate complex systems
  • Zoom out to observe large-scale interactions

Experiment freely and discover how gravity shapes motion in this interactive physics simulation.
